Traveloop 🌍✈️

Traveloop is a modern travel planning web application built for the Odoo x KAHE Coimbatore Hackathon '26.

The platform helps users:

Plan trips
Explore cities
Manage travel budgets
Organize itineraries
Track activities
Store travel notes
Manage packing checklists
🚀 Features
User Authentication UI
Dashboard Overview
Create & Manage Trips
Budget Tracking
Itinerary Planner
Timeline View
Packing Checklist

Responsive Modern UI

⚡ Installation

Clone the repository:

git clone https://github.com/vishnu-2007-codeyy/travelling-app.git

Move into project folder:

cd travelling-app

Install dependencies:

npm install

Run development server:

npm run dev
🌐 Local Development

Application runs on:

http://localhost:5173
