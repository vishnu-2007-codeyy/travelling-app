# Traveloop ✈️🌍

### Smart Travel Planning Platform for Modern Explorers

---

## 🚀 Overview

Traveloop is a modern full-stack inspired travel planning platform built for the **Odoo x KAHE Coimbatore Hackathon '26**.

The application helps travelers:

* Plan journeys efficiently
* Organize itineraries
* Track budgets
* Explore destinations
* Manage activities
* Maintain travel notes
* Build packing checklists

Designed with a clean modern UI and scalable architecture, Traveloop focuses on delivering a seamless travel management experience.

# ⚡ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/vishnu-2007-codeyy/travelling-app.git
```

---

## 2️⃣ Move Into Project

```bash
cd travelling-app
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Start Development Server

```bash
npm run dev
```
